# m3u8-parser

Библиотека для парсинга M3U8-плейлистов.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run lint` | Проверка рекомендуемых правил Biome |
| `npm run lint:fix` | Применение безопасных исправлений линтера |
| `npm run format:check` | Проверка форматирования без изменения файлов |
| `npm run format` | Форматирование файлов с помощью Biome |
| `npm run typecheck` | Проверка типов библиотеки, конфигураций и тестов |
| `npm run build` | Проверка типов, сборка Vite и генерация деклараций |
| `npm test` | Однократный запуск Vitest |
| `npm run docs` | Генерация HTML-документации из TypeScript и JSDoc |
| `npm run docs:watch` | Обновление документации при изменениях |
